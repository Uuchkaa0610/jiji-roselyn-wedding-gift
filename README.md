# Jiji & Roselyn — Wedding Memory Gift

A private, white-and-gold wedding keepsake built with Next.js and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy on Vercel

1. Import this GitHub repository in Vercel.
2. Keep the detected framework as **Next.js**.
3. Deploy with the default settings.

Vercel supplies the production URL automatically. You can optionally set
`NEXT_PUBLIC_SITE_URL` to a custom domain so social-sharing metadata uses it.
